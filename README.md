# English Quest — portfolio site

An 8-bit portfolio where each quarter is a level. Quarter 1 is playable; Quarters 2–4
exist as locked "in development" screens so the structure is visible from day one.

## Files

```
index.html        Title screen + overworld level map
quarter-1.html    Level 1 — the five rubric stages
quarter-2/3/4     Locked levels, marked in development
sports.html       Side quest: seasons, stats, sports writing
coding.html       Side quest: projects, including this site
journal.html      Penzu log + marble notebook
room-218.html     "Heard in Room 218" quote board
css/style.css     All styling — palette lives at the top
js/game.js        Save file, XP bar, level unlocking, sound
assets/           Put your screenshots and photos here
```

## Running it

Double-click `index.html`. That's it — no build step, no dependencies.

To put it online, drag the whole folder into Netlify Drop, or push it to a GitHub
repo and turn on GitHub Pages. Both are free and both serve plain HTML.

## Editing it

**Change the colors.** Everything comes from the variables at the top of
`css/style.css`. Change `--cyan` and the whole site follows.

**Fill in the empty slots.** Anything that says "Title, date, and a link…" is a
placeholder. Replace the text inside `<div class="slot">`. Add
`class="slot slot--filled"` once it holds real work — the border turns green.

**Add an image:**

```html
<div class="slot slot--filled">
  <b>Essay 1</b>
  <img src="assets/essay-1.png" alt="First page of the essay" style="width:100%">
</div>
```

**Move a progress bar.** Change the inline `width` percentage:

```html
<div class="bar"><i style="width:40%"></i></div>
```

**Add a stage to a quarter.** Copy a whole `<section class="stage">` block, give it a
new `data-stage="q1-something"` value, and add that same value to the `QUARTERS.q1`
array in `js/game.js` so it counts toward the XP bar.

**Build Quarter 2.** Copy `quarter-1.html` over `quarter-2.html`, then add
`q2: ["q2-formal", ...]` to the `QUARTERS` object in `js/game.js` and flip the `open`
check in `wireMap()` so `q2` opens once `quarterCleared("q1")` is true.

## Notes

- Progress saves to `localStorage`. Some browsers block storage for pages opened
  straight off the hard drive, so progress may reset until the site is hosted. The
  code falls back to memory and keeps working either way.
- Sound is off until you turn it on. The blips are generated by the Web Audio API,
  so there are no sound files in the folder.
- The two fonts (Press Start 2P and VT323) load from Google Fonts. Offline, the site
  falls back to a monospace stack and still reads fine.
