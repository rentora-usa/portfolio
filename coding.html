This site

This website is hand written in HTML, CSS, and JS using Github for the frontend. Visual Studio Code was used as my IDE.

  • Pixel art drawn as inline SVG rectangles rather than image files
  • Progress saved to localStorage, with a memory fallback when the browser blocks it, to save me from coding a backend as well.
  • Sound effects generated by the Web Audio API — no audio files to load
  • Keyboard focus outlines and reduced-motion support built in

Why did I put this in my portfolio?

When you think about it, writing an essay and coding are very similar. For one, there is grammar involved in both. Both English and coding languages have a set of "grammar" - usually refered to as "syntax" in coding - that make up the lagnuages. There is a difference, though. In English, missing a comma means you get a couple points off. Missing a semicolon in code means that your entire website could crash.

In addition, both start from a blank page- literally. You have to start from scratch and build up your essay or code from nothing. You have to think about what you want to say, how you want to say it, and how to make it look good. In coding, you have to think about what you want your website or app to do, how you want it to look, and how to make it work. Both require a lot of thought and planning before you even start writing or coding.

There are so many other reasons why they are both so similar, however this is not the section to talk about it.
